# 字幕节奏校对台（Subtitle Rhythm Desk）

本地运行的字幕节奏校对工具：导入 SRT 字幕与浏览器可播放的音频，在同一时间轴上查看字幕块与实时播放头，
用拖动完成边界微调，全程受「不重叠 / 最短时长 / 最小间隔」约束保护，越界自动回弹并标出原因；
支持点击字幕定位播放、撤销/重做，并导出按时间顺序重新编号的 SRT。

纯前端实现（React 18 + TypeScript + Vite），文件只在浏览器本地处理，不上传任何服务器。

## 一键启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问： **http://localhost:8080**

停止：

```bash
docker compose down
```

## 必要配置

- **端口**：默认占用宿主机 `8080`。若该端口被占用，任选其一：
  ```bash
  HOST_PORT=9090 docker compose up -d --build
  ```
  或直接修改 `docker-compose.yml` 中 `"${HOST_PORT:-8080}:80"` 冒号左侧的端口。
- 无需任何 API Key、后端服务或网络依赖；SRT 与音频均通过浏览器本地读取。
- 浏览器要求：支持 ES2020 的现代浏览器（Chrome / Edge / Firefox / Safari 近年版本均可）。
- 音频格式：浏览器 `<audio>` 可播放的格式（MP3、WAV、OGG、AAC、FLAC 等，视浏览器而定）。

## 本地开发（不用 Docker 时）

```bash
npm install
npm run dev        # 开发服务器，访问 http://localhost:5173
npm run build      # 类型检查 + 产出 dist/
npm run preview    # 本地预览构建产物
```

## 操作说明

| 操作 | 行为 |
| --- | --- |
| 点击字幕块 | 选中并将播放头定位到该条起点（自动 seek） |
| 拖动字幕块中间 | 整条平移，保持时长不变 |
| 拖动左/右边界手柄 | 调整开始/结束时间，吸附到 5 ms |
| 点击时间轴空白处 | 播放头跳转到点击位置 |
| 空格 | 播放 / 暂停 |
| `Ctrl+Z`（macOS `⌘Z`） | 撤销上一次边界调整 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| 顶部「－ / ＋」 | 时间轴缩放（10–600 px/s） |

### 拖动约束（实时钳制 + 回弹提示）

1. **不重叠**：左边界不得越过「上一条结束 + 最小间隔」；右边界不得越过「下一条开始 − 最小间隔」。
2. **最短时长**：任一边界调整后，单条时长不得短于设定的「最短时长」。
3. **最小间隔**：相邻字幕之间必须保留设定的「最小间隔」。
4. **时间范围**：起点不早于 0；音频已加载时，终点不超出音频时长。

发生越界时，字幕块红框高亮并自动回弹到允许位置，时间轴顶部显示具体原因（如
「与下一条字幕至少间隔 120 ms，已回弹」）。约束参数（最短时长 / 最小间隔，单位 ms）
可在顶部工具栏调整，并保存在浏览器 localStorage 中。

### SRT 导入 / 导出

- 导入：兼容标准 SRT（逗号或点作为毫秒分隔均可），非法条目自动跳过，并按开始时间排序。
- 导出：按开始时间升序重新连续编号（`1, 2, 3 …`），时间格式统一为 `HH:MM:SS,mmm`，
  保证导出文件编号与时间顺序一致。

## 目录结构

```
├── Dockerfile              # 多阶段构建：node 构建 + nginx 托管
├── docker-compose.yml      # 一键启动，默认映射 8080:80
├── nginx.conf              # SPA 回退与静态资源缓存
├── index.html
├── vite.config.ts
└── src
    ├── App.tsx             # 页面框架、导入导出、快捷键、音频状态
    ├── components
    │   └── Timeline.tsx    # 刻度尺 / 字幕块 / 播放头 / 拖拽回弹
    ├── hooks
    │   └── useHistory.ts   # 边界调整的撤销/重做栈（上限 200 步）
    ├── lib
    │   ├── srt.ts          # SRT 解析、序列化、时间格式化
    │   └── constraints.ts  # 邻居边界与三类约束的纯函数钳制逻辑
    ├── types.ts
    └── styles.css
```
